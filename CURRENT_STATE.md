## Accepted information-relationship architecture

The Production is persistent scope.

Descriptive information orientations are:

- **current possibility** — conditions, people, relationships, knowledge, pressures, options and Scene setup relevant now;
- **present performance** — what is happening now and whose agency is salient;
- **causal history** — what became authoritative, what changed, and what remains unresolved.

Their relationship is recursive:

```text
POSSIBILITY
    -> PRESENT PERFORMANCE
    -> CAUSAL HISTORY
    -> changed future possibility
```

Persistent continuity anchors, subject to later implementation validation, include:

- Production identity;
- active Scene context;
- persistent Character/roster identity;
- active Presentation Perspective when disclosure is constrained;
- authority/effect status such as current, proposed/non-effective, accepted historical, or unresolved;
- blocking capability state when a requested function is unavailable.

History inspection must not silently move authoritative current state backward. Provisional Performance must not visually collapse into accepted/effective history. Accepted historical texture must not be mistaken for a permanent durable state field merely because it happened.

## Accepted shell/navigation grammar

Structural rule:

> **Navigate between durable scopes; transition within one Production by following meaning.**

### Level 0 — Application / Production scope

Durable navigation for entering, opening, switching or leaving a persistent Production and for app-level settings/help/diagnostics when later required.

### Level 1 — Persistent Production workspace

One continuous workspace retaining the semantic anchors needed to know which Production, Scene, perspective and current/history context the creator is operating in.

### Level 2 — Meaning-linked focus transitions

Possibility, performance and history are reached through contextual transitions such as inspecting relevant conditions, tracing causes, reviewing what changed, and returning to current context. They are not automatically top-level menu items.

### Level 3 — Inspectors and transient command surfaces

Deep or adjacent information such as causal provenance, consequence detail, Character context, unresolved pressure or diagnostics appears contextually rather than becoming permanent global navigation.

Candidate semantic shell regions remain:

- scope/identity;
- minimum current-context anchors;
- one primary work surface;
- optional contextual inspector;
- task-relevant command surface;
- semantic status when authority, perspective, current/history state or capability materially matters.

`Back` means navigation history only. It must never silently mean undo, rewind, reject, retcon, branch or mutate authoritative Production history.

Wide/medium/narrow windows may change pane arrangement, but no essential meaning may depend on simultaneous multi-column display. One-window completeness remains the baseline.

The shell must be computationally quiescent when state is unchanged: no baseline dependence on continuous animation, graph physics, polling, idle inference, or persistent GPU/NPU work.

## Accepted causal-session prototype

The prototype tests one uninterrupted creator session:

```text
OPEN / RESUME PRODUCTION
        ↓
CURRENT SCENE / WATCH
        ↓
INSPECT RELEVANT CONTEXT
        ↓
RETURN TO CURRENT SCENE
        ↓
DIRECT / INTERVENE
        ↓
OPTIONAL CHARACTER-BOUNDED PERFORMANCE
        ↓
PROVISIONAL PERFORMANCE
        ↓
ACCEPTED / EFFECTIVE PERFORMANCE BOUNDARY
        ↓
WHAT CHANGED?
        ↓
TRACE CAUSE / HISTORY
        ↓
RETURN TO CHANGED PRESENT
        ↓
NEXT POSSIBILITY IS DIFFERENT
```

The final step is mandatory.

Core success feeling:

> **I am back in the same world, but it is different because of what happened.**

The prototype must not end on an Archive/summary surface merely because history was inspected.

## Active grayscale continuous-workspace wireframe

`docs/KYMAEAN_CONTINUOUS_WORKSPACE_GRAYSCALE_WIREFRAME_01.md` translates the accepted architecture into seven concrete structural frames:

1. **Present / Watch** — people and relationships dominate;
2. **Context expansion** — adjacent meaning without leaving the Production;
3. **Causal trace / historical focus** — history explains the present and is explicitly historical;
4. **Character-bounded perspective** — disclosure changes while Production truth remains the same;
5. **Provisional performance / authority boundary** — performance material is not automatically effective history;
6. **Consequence recognition** — the smallest useful explanation of what changed;
7. **Return to changed present** — same persistent world, changed current possibility.

The wireframe explicitly rejects as baseline assumptions:

- permanent Studio/Stage/Archive columns;
- permanent timeline navigation;
- transcript-dominant Stage experience;
- perspective as a separate product mode;
- color-only provisional/effective status;
- technical capability failure represented as fictional rejection;
- ending the causal loop on history rather than the changed present.

Adaptive rule:

- wide layouts may use adjacent context when it genuinely improves comprehension;
- medium layouts may use temporary drawers/details;
- narrow layouts must support sequential focus with deterministic Back/focus restoration;
- no essential meaning depends on simultaneous panes.

The low-fidelity interaction model is not complete unless it works without visual styling.

Required semantic distinctions:

- current versus historical material;
- Creator versus Character-bounded perspective;
- provisional versus effective/accepted material;
- selected Character/current object;
- consequence and unresolved status;
- disabled/unavailable AI capability versus fictional in-world state.

Keyboard users must be able to complete the full causal loop.

Reduced motion must preserve every navigation/state meaning.

High contrast/scaling must not depend on subtle borders, glow, portrait color, spatial distance, or simultaneous multi-column layout.

AI capability failure must remove automation without corrupting creative truth, inventing fictional Character behavior, or creating causal history from a technical failure.
