B

Interaction priority — what the Home is allowed to optimize

Re-entry beats library management.
01
Resume

Continue the current creative thread

The strongest action returns to the current work. It should not require the creator to rediscover the Production through a library or ontology.

02
Reorient

Recover situation, people, pressures, questions

Enough current meaning is visible to restore mental context without turning Home into the full Shaping workspace.

03
Follow meaning

Open Scene, situation detail, or relevant history

Secondary paths deepen the current Production. They preserve current/historical distinction and return to the same origin.

04
Switch / create

Reach other Productions without letting them dominate

Production switching, full browse, search and creation stay easy to find, but visually subordinate to the current Production.

E

Section laws and non-authority

The Home can become detailed without becoming final visual design.
Current Production before libraryThe app remembers where creative attention was, rather than making re-entry begin with project selection.
Meaning before metadataSituation, stakes and consequential movement outrank file-like facts, model details or generic activity logs.
Resume is not “Play”The primary action returns to current work; it does not imply a frozen Scene lifecycle or Stage execution command.
History stays causalRecent material should help explain the present. It must remain distinguishable from current state and generic audit chronology.
Healthy persistence stays quietExceptions surface truthfully. Technical failure never becomes Character action, silence, refusal or Production history.
Theme changes appearance, not hierarchyLight and Dark preserve the same order, commands, state distinctions, focus logic and dark Stage/preview semantics.

Still explicitly open

  • Final labels, icons, typography, palette, material and motion.
  • Whether Productions use imagery/cover art at all.
  • Exact Scene lifecycle and “begin next Scene” control.
  • Consequence review, Perspective switching, Take/Rehearsal/branching.
  • Provider/model/cost, Performer assignment, portable Production and export workflow.
  • WinUI/XAML, native accessibility/runtime, ARM64/package/Store behavior.
Section conclusion: Production Home / Resume is ready for later visual-language integration without further architectural redraw.
Detailed functional target = current Production + resume point → concise current meaning → causal/supporting routes → subordinate Production switching.
