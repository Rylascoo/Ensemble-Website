## Candidate thesis

The public prelaunch site should do more than say "Coming Soon," but it should not pretend the unfinished application UI or unsettled product design is already final.

It therefore communicates only frozen/stable ideas:
1. Kymaean is a local-first generative theater and creative simulation for persistent characters.
2. The creator establishes people and conditions.
3. Characters persist beyond any single model performance.
4. Accepted performance becomes causal history.
5. Consequence changes what future scenes can mean.
6. Creator authority remains primary.
7. Local-first means local sovereignty.
8. The product remains in development for Windows 11 ARM64.

No final Stage layout, creator-posture hierarchy, provider UX, perspective-switching UX, Archive UX, interaction taxonomy or unready application design is shown.

## Why this can replace the placeholder

The current production site communicates identity and atmosphere well but gives a visitor almost no product understanding.

This candidate preserves:
- Stage authority;
- monumental negative space;
- sparse dark materiality;
- exact identity separation from artwork;
- no fantasy portal language;
- no app screenshot imitation;
- reduced-motion and forced-colors fallbacks.

It adds:
- frozen product thesis;
- persistent-character distinction;
- causal-history proposition;
- creator-ownership principle;
- local-first principle;
- a coherent page-length visual journey.
