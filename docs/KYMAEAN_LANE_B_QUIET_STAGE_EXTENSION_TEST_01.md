## 01 — Bounded Chorus

Job:
**relationship / bounded perspective**

Three distinct people occupy one shared present:
- Wren knows the promise;
- Elias knows the letter;
- Mara knows neither cause.

The same event text is distributed differently across the three presences. Each person receives a different emphasized fragment while unavailable information remains visibly present but diminished.

Design law:

**Relationship is the composition of unequal access to one present, not a connector diagram.**

### Strengths

- preserves distinct people rather than anonymous nodes;
- makes asymmetrical knowledge immediately legible;
- one authoritative event can support multiple bounded readings;
- no portrait, color, motion, exact position, hover, or connector line is required for identity;
- remains theatrical/editorial rather than app-like.

### Pressure

The three-column desktop field has some structural severity. Future refinement should avoid drifting into a comparison table.

Result:

**PASS — recommended non-cone relationship grammar.**

## 02 — Causal Scar

Job:
**history / Archive / consequence**

A proposed event begins without structural displacement.

An accepted consequence creates a visible scar through the field. Later events begin progressively farther across the page because the earlier state of possibility no longer exists.

Design law:

**History should deform the page that follows it.**

### Strengths

- consequence changes composition rather than becoming decoration;
- accepted vs merely proposed remains visually distinguishable;
- later material inherits earlier change;
- does not require transcript playback or a permanent timeline UI;
- permits a light material field inside the broader Quiet Stage world, preventing permanent-black monotony.

### Audit correction

The first render used four full-width table-like rows. That read too much like an Archive timeline.

The rows were removed. Events now move across one continuous field around a persistent causal scar.

Result:

**PASS — strongest non-cone extension in this round.**

## 03 — Posture Proximity

Job:
**creator posture / Production invitation**

One living scene occupies the center.

The four creator postures are positioned by their relationship to that scene:
- Watch remains outside;
- Direct changes pressure/circumstance without becoming a Character;
- Perform enters through a Character-bound role;
- Write authors directly.

Design law:

**Posture is a relationship to the Production, not four equal product cards.**

### Strengths

- avoids dashboard-card treatment;
- creator authority remains conceptually stable while mode of participation changes;
- one Production stays visually central;
- readable without color or motion;
- suitable for acquisition explanation without pretending to be native UI.

### Audit correction

The first render connected posture labels to the scene with diagram lines.

Those connectors were removed. Distance and placement now carry the relationship.

Result:

**PASS — recommended non-cone creator-posture grammar.**

## Typography / readability correction

The first complete render used several 8–9 px supporting text values inherited from design-board conventions.

Because this artifact resembles a real web composition, those values could be misread as a production typography baseline.

Readable supporting text was raised; only genuine metadata microcopy remains small.

This is still static design evidence, not accessibility-runtime validation.

## Falsification result

Quiet Stage **survives** the required extension test.

The visual-world thesis no longer depends on cone imagery alone.

A coherent broader grammar now exists:

- **Hero / product truth:** theatrical presence, current Stage evidence permitted;
- **Relationship:** bounded chorus / unequal access;
- **History:** causal scar / structural deformation;
- **Creator posture:** proximity to one living Production.

These systems share restraint, theatrical absence, human causality and living consequence without repeating one visual device.

## Recommendation

Promote the following as **temporary V0 website visual-world extension laws**, subject to Director confirmation:

1. Quiet Stage remains the primary V0 visual-world incumbent.
2. Cone imagery is reserved for genuine Stage/product-truth roles; it is not the universal website motif.
3. Relationship may be expressed through unequal availability inside one shared present.
4. Accepted consequence may visibly deform later composition.
5. Creator postures may be expressed through spatial relationship to one Production rather than equal feature cards.
6. The website may use light material fields where the subject benefits; Quiet Stage does not require permanent black.
7. No extension grammar gains authority over Production truth or native app semantics.
