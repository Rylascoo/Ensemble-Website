# R0 Renderer Cartography — Persistent Affordance Carrier Design 03

Status: **DIRECTOR DESIGN CHECKPOINT — NO RENDER AUTHORIZED**

Updated: 2026-09-03

## Purpose

PAC-01B replaced generic fixed infrastructure with ordinary movable elements, but the renderer treated those elements as a collection of familiar single-object affordances.

Canonical result:

`docs/R0_RENDERER_CARTOGRAPHY_PAC_01B_RESULT.md`

The next test isolates the remaining variable:

> **relational configuration dependence**

without adding a new carrier class, explicit modification trace, environment, narrative, technology, or metaphor.

## Empirical ladder so far

PAC-01A:

> generic built carrier -> plural supported use

PAC-01B:

> repositionable ordinary objects -> plural object-level use

Remaining target:

> relational configuration -> emergent capability produced by the arrangement itself

The key correction is:

> **Object affordance is not configuration affordance.**

## New hypothesis

> **A persistent enabling condition becomes more causally legible when several independent present actions visibly depend on relationships among ordinary elements rather than on any one element alone.**

The configuration remains an experimental measurement device. It has no aesthetic or identity inheritance rights.

## PAC-01C

Name:

**Persistent Affordance Carrier 01C — Relational Configuration / Emergent Affordance**

Research question:

> Can ordinary movable elements become a capability-bearing configuration when multiple independent human actions visibly depend on their relationship to one another?

## Controlled semantic requirements

- several distinct people remain the primary visual structure;
- a few ordinary movable human-made elements were arranged before the depicted moment into one modest shared configuration;
- the original arranging action is not shown;
- several people independently use the same configuration at the same time for different actions;
- at least two ongoing actions must visibly depend on the relationship among multiple elements rather than on any single element by itself;
- the elements remain recognizable as ordinary everyday things;
- they are not specially built or modified for the depicted purpose;
- no person's action depends on another person guiding, helping, directing, rescuing or controlling them;
- the configuration remains modest and visually subordinate to the people;
- the surrounding world remains restrained.

## Draft sterile packet — NO RENDER AUTHORIZED

> Create one uninterrupted artwork centered on several distinct people whose presence and relationships are necessary to the image.
>
> A few ordinary movable human-made elements were arranged before this moment into one modest shared configuration. Several people are independently using that same configuration at the same time for different actions. At least two of those actions should visibly depend on the relationship among multiple elements, rather than on any single element by itself, so the arrangement itself is what makes those uses workable.
>
> Keep the elements recognizable as ordinary everyday things. They should not appear specially built or modified for this purpose. The original act of arranging them is not shown.
>
> Keep every person specific and self-directed. No one should guide, help, direct, rescue, or control anyone else. Keep the configuration visually subordinate to the people.
>
> Keep the surrounding world restrained. Let posture, orientation, spacing, and independent use reveal why the relationship among the elements matters.
>
> Return only the uninterrupted artwork, with no text or surrounding presentation layout.

## Recursive packet audit

### Variable isolation

PAC-01C deliberately keeps the same broad carrier class as PAC-01B: ordinary movable human-made elements. It changes only the required level of affordance from object-level use to relationship-dependent use.

This avoids confounding the result with a new material, object family, environment, historical trace, technology, or architectural device.

### Object/setting seeding

The packet names no specific furniture, tool, workplace, home, institution, public site, culture, era, architecture, technology or medium.

### Main success criterion

The arrangement must be visibly more than a set of useful things placed near one another.

At least two actions should make sense because **multiple elements are in a particular relationship**.

### Principal risk — contraption / installation

Requiring relational dependence may cause the renderer to invent:

- a contraption;
- a modular furniture system;
- an installation;
- a stage;
- a product demonstration;
- a specially engineered device.

Those are failures if the object system becomes visually or semantically primary.

### Secondary risk — standard furniture schema

The renderer may produce ordinary table/chair or bench/table layouts where people merely use each object conventionally. If the actions remain attributable to single objects rather than their relationships, record failure; do not rerender PAC-01C.

### Attractor safeguards

Reject/stop if the result becomes:

- bridge/path/door/threshold/route logic;
- repair scaffolding or damage response;
- accessibility/accommodation shorthand;
- monumental architecture;
- progress/achievement symbolism;
- environment-first spectacle;
- helper/recipient hierarchy.

These safeguards are Director-side evaluation criteria and should not be added to the sterile renderer packet.

## Evaluation gates

### PACC1 — Relational configuration legibility

Does the image visibly contain one coherent arrangement rather than unrelated useful objects?

### PACC2 — Persistence

Is the configuration already present and usable after the arranging action has ended?

### PACC3 — Emergent plural affordance

Do at least two meaningfully different independent actions visibly depend on relationships among multiple elements rather than on individual objects alone?

### PACC4 — Common-cause readability

Can the same persistent configuration plausibly be read as the common enabling condition behind those different actions?

### PACC5 — Independent agency

Do people remain self-directed without helper/recipient, leader/follower or controller/controlled hierarchy?

### PACC6 — Human primacy

Do people carry most of the artwork's action and meaning?

### PACC7 — Ordinary/non-symbolic carrier

Do the elements remain mundane rather than becoming a product, exhibit, installation, special technology or symbolic device?

### PACC8 — Attractor suppression

Does the result avoid route/access/threshold/repair/monumental/progress imagery and environment-first spectacle?

## Render budget and stop rule

Budget: **one image**.

Use one fresh regular non-project Renderer Context. No correction chain.

After the first returned image is archived and evaluated, stop before introducing modification traces or another carrier topology.
