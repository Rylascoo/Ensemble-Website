## Principal finding

PAC-01D establishes that one shared arrangement can support overlapping independent uses, but a renderer may satisfy that requirement by collapsing the common cause into one dominant hub object.

Durable distinction:

> **Shared-element overlap is not the same as distributed configuration dependence.**

A common hub object can support several overlapping uses without making relationships among multiple elements the capability-bearing cause.

## Empirical ladder

- PAC-01A: generic built carrier -> plural supported use;
- PAC-01B: repositionable ordinary objects -> plural object-level affordance;
- PAC-01C: local relationships among ordinary objects -> local emergent affordance;
- PAC-01D: one shared arrangement -> overlapping use, but hub-object collapse;
- unresolved: one shared persistent configuration -> several independent uses where no single element is sufficient and multi-element relationships are causally necessary.
