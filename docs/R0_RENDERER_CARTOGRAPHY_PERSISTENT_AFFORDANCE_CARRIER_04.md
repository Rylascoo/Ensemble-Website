# R0 Renderer Cartography — Persistent Affordance Carrier Design 04

Status: **DIRECTOR DESIGN CHECKPOINT — NO RENDER AUTHORIZED**

Updated: 2026-09-03

## Purpose

PAC-01C demonstrated that ordinary elements can produce genuine relational affordances when multiple elements are used together. It failed to make one shared persistent configuration the common enabling condition behind different actions.

Canonical result:

`docs/R0_RENDERER_CARTOGRAPHY_PAC_01C_RESULT.md`

The next test isolates the remaining variable:

> **shared overlapping configuration**

without introducing a new carrier class, explicit modification trace, environment, narrative, technology or metaphor.

## Empirical ladder so far

PAC-01A:

> generic built carrier -> plural supported use

PAC-01B:

> repositionable ordinary objects -> plural object-level use

PAC-01C:

> local relationships among ordinary objects -> local emergent affordance

Remaining target:

> one persistent shared configuration -> multiple independent actions enabled by overlapping relationships within the same arrangement

The key correction is:

> **Multiple local configurations are not the same as one shared capability-bearing configuration.**

## New hypothesis

> **A persistent enabling condition becomes legible as a common cause when different independent actions rely on overlapping relationships within the same small set of ordinary elements.**

The configuration remains an experimental measurement device. It has no aesthetic or identity inheritance rights.

## PAC-01D

Name:

**Persistent Affordance Carrier 01D — Shared Overlap / Common-Cause Configuration**

Research question:

> Can one modest arrangement of ordinary movable elements visibly function as the common enabling condition for several different independent human actions?

## Controlled semantic requirements

- several distinct people remain the primary visual structure;
- a few ordinary movable human-made elements were arranged before the depicted moment into one compact shared configuration;
- the original arranging action is not shown;
- several people independently use the same configuration at the same time for different actions;
- at least two different actions each depend on relationships among multiple elements;
- those actions rely on some of the same elements rather than on disjoint local pairings;
- the elements remain ordinary and recognizable rather than specially built or modified for the depicted purpose;
- no person's action depends on another person guiding, helping, directing, rescuing or controlling them;
- the configuration remains modest and visually subordinate to the people;
- the surrounding world remains restrained.

## Draft sterile packet — NO RENDER AUTHORIZED

> Create one uninterrupted artwork centered on several distinct people whose presence and relationships are necessary to the image.
>
> A few ordinary movable human-made elements were arranged before this moment into one compact shared configuration. Several people are independently using that same configuration at the same time for different actions. At least two different actions should each depend on relationships among multiple elements, and those actions should rely on some of the same elements, so one persistent arrangement is visibly supporting more than one kind of use.
>
> Keep the elements recognizable as ordinary everyday things. They should not appear specially built or modified for this purpose. The original act of arranging them is not shown.
>
> Keep every person specific and self-directed. No one should guide, help, direct, rescue, or control anyone else. Keep the shared configuration visually subordinate to the people.
>
> Keep the surrounding world restrained. Let posture, orientation, spacing, and independent use reveal how the same arrangement supports different actions.
>
> Return only the uninterrupted artwork, with no text or surrounding presentation layout.

## Recursive packet audit

### Variable isolation

PAC-01D deliberately keeps the same broad carrier class as PAC-01B and PAC-01C: ordinary movable human-made elements.

It changes only one requirement:

- PAC-01C permitted relational affordance in separate local pairings;
- PAC-01D requires multiple actions to depend on overlapping subsets of the same arrangement.

This is the smallest available move from local relational affordance to shared common-cause affordance.

### Object/setting seeding

The packet names no specific furniture, tool, workplace, home, institution, public site, culture, era, architecture, technology or medium.

### Main success criterion

The image must show one coherent modest arrangement whose same elements participate in more than one independent use.

At least two different actions must rely on overlapping portions of that arrangement.

### Principal risk — collaborative-table collapse

The renderer may reduce the requirement to several people independently using the same table or surface. If the shared object alone explains the uses, rather than relationships among multiple elements, record failure.

### Secondary risk — contraption / installation

Overlapping relational dependence may cause the renderer to invent a specially engineered device, modular system, installation or product demonstration. Those are failures if the carrier becomes semantically or visually primary.

### Tertiary risk — forced interpersonal coordination

Shared use of the same arrangement may cause cooperative, helper or leader/follower behavior. If one person's use depends primarily on another person's action rather than on the persistent configuration, record failure.

### Attractor safeguards

Reject/stop if the result becomes:

- bridge/path/door/threshold/route logic;
- repair scaffolding or damage response;
- accessibility/accommodation shorthand;
- monumental architecture;
- progress/achievement symbolism;
- environment-first spectacle;
- helper/recipient hierarchy.

These remain Director-side evaluation criteria and should not be added to the sterile renderer packet.

## Evaluation gates

### PACD1 — One shared configuration

Does the image visibly contain one coherent modest arrangement rather than multiple separate local pairings?

### PACD2 — Persistence

Is the configuration already present and usable after the arranging action has ended?

### PACD3 — Overlapping relational affordance

Do at least two meaningfully different independent actions each depend on relationships among multiple elements, with some of those elements shared across the actions?

### PACD4 — Common-cause readability

Can the same persistent arrangement plausibly be read as the common enabling condition behind the different actions?

### PACD5 — Independent agency

Do people remain self-directed without helper/recipient, leader/follower or controller/controlled hierarchy?

### PACD6 — Human primacy

Do people carry most of the artwork's action and meaning?

### PACD7 — Ordinary/non-symbolic carrier

Do the elements remain mundane rather than becoming a product, exhibit, installation, special technology or symbolic device?

### PACD8 — Attractor suppression

Does the result avoid route/access/threshold/repair/monumental/progress imagery and environment-first spectacle?

## Render budget and stop rule

Use one fresh regular non-project Renderer Context. No correction chain.

After the first returned image is archived and evaluated, stop before introducing modification traces, a new carrier topology or a new environmental mechanism.
