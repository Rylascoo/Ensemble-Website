## What PAC-01B proved

The renderer can replace generic fixed architecture with ordinary movable human-made elements while preserving:

- human primacy;
- individual specificity;
- independent agency;
- ordinariness;
- non-symbolic use;
- suppression of bridge/path/threshold/repair/monumental attractors.

The image plausibly contains deliberately movable/repositionable elements: chairs, narrow tables, a crate, bags and ordinary personal objects.

## Decisive failure

The different human actions are primarily the familiar affordances of individual objects:

- chair -> sitting / reading;
- table -> writing;
- crate -> sitting while tying a shoe;
- chair -> sitting while using a phone.

Those actions do not visibly depend on the **relationships among the elements**. If the objects were separated, most of the depicted actions would remain intelligible.

Therefore the configuration itself does not become the capability-bearing unit.

## New empirical distinction

> **Object affordance is not configuration affordance.**

PAC-01A showed a generic built carrier supporting plural use.
PAC-01B showed repositionable ordinary objects supporting plural object-level use.

The remaining unresolved target is:

> **relational configuration -> emergent capability produced by the arrangement itself**

## Measurement correction

The next experiment should require that at least two independent actions visibly depend on relationships among ordinary elements rather than on any one element alone.

Simply asking for elements to be `positioned together` is insufficient; the renderer interprets that as a mundane constellation of individually useful objects.
