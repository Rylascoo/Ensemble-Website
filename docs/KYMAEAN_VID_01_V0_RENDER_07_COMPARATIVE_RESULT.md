### Parallel action islands

Both images also expose a stronger AFI distinction:

> **Several locally specific actions can each affect nearby composition while the total image still behaves as a set of parallel action islands.**

Promoted distinctions:

```text
local action-responsive composition
!=
distributed action-field interdependence

!=

formal orthogonality
!=

```

### Propagation requirement

The missing property is not simply more activity.

A successful H5 field should make visible consequence propagate across multiple people:

```text
Action A changes the usable/visual situation of B
-> B visibly adapts through a different action
-> B's adaptation changes the usable/visual situation of C
-> C acts inside that changed field
```

No shared intention, harmony or private awareness need be asserted.

The relevant falsification test becomes downstream:

> **If A's action changed while A remained nearby, would B's action and at least one downstream region involving C need to reorganize? If not, the field may still be a collection of local action islands.**
