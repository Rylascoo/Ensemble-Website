## Hypothesis family H1 — body-conforming coupled inversion return

### Core geometry

A broad finite-thickness laminar field has a simple approximately parallel upper/lower baseline on both sides of the human cluster.

A's passive lateral pelvis/lower-torso load locally forces the upper field boundary downward into a **body-conforming compression/inversion pocket**. The changed boundary must visibly approach and wrap the actual A load silhouette at the contact zone rather than form a freestanding seat-shaped bowl.

The same continuous material immediately exits that compressed zone as one **upward and inward return fold**. That return fold supplies B's only support position.

The field then relaxes back toward the same simple parallel baseline beyond B.

### Causal read

`A body contact visibly indents/compresses the field`
`-> the same upper/lower boundaries and one internal correspondence continue through a coupled return fold`
`-> B is carried upward/inward on that return`
`-> one direct A↔B forearm relation becomes available`

### Why it differs from Candidate 04

Candidate 04 asked the viewer to infer load from A occupying a broad pre-shaped depression.

H1 requires the deformation to be **contact-shaped by A**:

- deformation width is locally tied to A's actual load footprint rather than a general basin;
- field curvature meets A's body at visible load-contact tangencies;
- the displaced return begins adjacent to that contact zone;
- no empty seat-like pocket remains legible as a complete designed object if A is mentally removed;
- both outer boundaries remain visible through the changed region so the field reads as a deformed laminar condition rather than terrain.

### Strengths

- strongest direct visual evidence that A is physical input rather than occupant;
- D4 inversion/return provides stronger non-baseline state evidence than smooth topography;
- upper/lower boundary continuity can carry redundant baseline correspondence;
- B uses a different support class from A;
- no third clue object is required;
- compact enough for mobile core.

### Risks

- cushion/hammock/furniture reading;
- folded-sheet/material-installation dominance;
- return fold may look like a purpose-built ledge;
- body-conforming indentation may become too soft/comfortable;
- fold may become the spectacle rather than infrastructure.

### Safeguards

- no external frame, suspension point, legs, base, rail, bracket, seam hardware or seat architecture;
- no closed or symmetrical seat pocket around A;
- A load contact is oblique/lateral rather than an upright chair pose;
- return fold is one continuation of the changed material, not a detached shelf;
- B has no stable support if the return is restored to baseline;
- fold amplitude is only what is needed for the positive-margin relation;
- people remain larger/more semantically salient than the fold event;
- sanitized transfer representation must pass the pre-existing-form ambiguity test before Stage 7.
