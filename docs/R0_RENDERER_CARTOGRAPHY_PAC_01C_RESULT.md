## Result

PAC-01C advances beyond PAC-01B in one important respect: several actions now visibly depend on relationships among multiple ordinary elements rather than on single-object affordances alone.

Examples in the returned image include:

- a reader reclining across one chair while using a second chair as leg support;
- a person seated in a folding chair while using a crate as a footrest;
- a central writer using a chair in relation to a low work surface.

Relational affordance is therefore visually recoverable.

However, the scene does not make one shared persistent configuration the common enabling condition behind the different actions. Instead, the renderer fragments the overall field into several local micro-configurations or pairings. The object relationships are productive locally, but the full constellation is not legibly one capability-bearing arrangement shared by multiple people.

## Principal finding

> **Relational affordance can emerge locally without producing shared systemic affordance.**

## Durable distinction

> **Multiple local configurations are not the same as one shared capability-bearing configuration.**

PAC-01C therefore narrows the unresolved target from `configuration affordance` in general to **shared common-cause configuration**.

## Method implication

Do not introduce a new carrier class, modification trace, architecture, environment, technology or narrative yet.

The smallest next variable is:

> **overlapping use of the same persistent configuration**

At least two independent actions should rely on overlapping subsets of the same small set of ordinary elements so that one persistent arrangement is visibly the common enabling condition behind different uses.
