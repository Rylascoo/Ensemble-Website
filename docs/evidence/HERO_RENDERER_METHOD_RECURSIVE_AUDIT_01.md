Historical Renderer Cartography correctly used one-variable contrasts to learn renderer behavior. R0 Final Synthesis explicitly closed further calibration by default. Result: PASS.

### A3 — Free-reroll / method-invalid ambiguity — CORRECTED

A broad `method-invalid` class could allow weak visible outputs to be discarded, conflicting with the frozen rule that a weak but evaluable qualifying candidate still counts.

Correction: only genuine technical nulls with no judgeable visual candidate are non-counting. A weak, ordinary, branded, storyboard-like, semantically weak, surface-failing or otherwise visibly nonconforming candidate counts whenever enough visual evidence exists to judge failure. Unexpected multiple outputs are archived and stopped for Director accounting rather than cherry-picked.

Result: PASS.

### A4 — Candidate-specific responsive rescue — CORRECTED

The first method draft simultaneously allowed a crop/alignment rule to be frozen per packet and required the same harness across candidates. That was internally inconsistent and allowed potential candidate-specific rescue.

Correction: one global `Hero Integration Harness 01` must be frozen before the Qualifying Round 01 package. Its desktop frame, identity/copy geometry, artwork placement, mobile frame and crop/alignment rule remain unchanged across all qualifying candidates. Each candidate is designed to survive the harness; the harness does not adapt to the candidate.

Result: PASS.

### A5 — Brief 02 non-threshold judgments — CORRECTED

The first method draft loosely grouped relational composition, Quiet Stage belonging, Mineral Theater compatibility and category distinctiveness with advisory observations. Brief 02 says these must also be judged, while only specific prior-author recoverability is explicitly advisory.

Correction: E8 now treats the first four as required non-threshold judgments. They must be recorded, but no new independent numeric advancement floor is invented after freeze. Specific prior-author recoverability remains explicitly advisory.
