PURPOSE

Reconcile one arithmetic/metadata defect discovered during Candidate 08 Stage 6M construction without changing any approved Stage 6 x/y geometry, support footprint, free-edge path, contact, responsive window, criterion or stage authority.

DEFECT

The approved Stages 1–5 / Stage 6 evidence carried a `120 px` B-support-to-free-edge planning clearance. That number was calculated as `824 - 704`, using the undeformed baseline foreground-edge y=824 against the left changed support-root center y=704.

The actual approved changed free-edge path is locally displaced upward. Therefore 120 px is only the obsolete baseline-edge planning value; it is not the exact changed-state clearance.

BINDING METRIC

The registered anti-edge metric is support-root/center to the foreground free-edge at the same source-space x coordinate. It is not outer-foot-polygon-edge clearance.

Controlling changed support root:
- x = 1105 px = 0.7194 normalized;
- y = 704 px = 0.7333 normalized.

The approved changed upper free edge brackets that x with normalized points:
- (0.7064, 0.8354);
- (0.7227, 0.8417).

Linear interpolation at x=0.7194 gives:
- edge y = 0.8404245398773006;
- edge y in source pixels = 806.8395582822086 px.

Correct changed-state support-root clearance:
`806.8395582822086 - 704 = 102.8395582822086 px`.

Frozen minimum:
`100 px`.

Correct positive surplus:
`2.8395582822086 px`.

The right support root has materially greater clearance and is non-controlling.

FIXED STAGE 6M PROJECTION

Stage 6M uses the already-frozen orthographic oblique projection. For two points on the same physical z plane, the fixed depth-y offset is identical and cancels from their vertical separation. The source-space support-root/edge clearance therefore remains 102.8395582822086 px under that fixed same-plane projection before raster/stroke thickness.
