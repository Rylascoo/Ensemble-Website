# SYM Symbol Exploration Framework 01

## Authority

Original C0 Threshold K is the immutable symbol reference selected during SYM-01.

C0 refers only to the preserved original Threshold K asset and must never be reused as a label for derived studies or new concepts.

## Exploration lanes

### Lane A — C0 Preservation

Purpose:
Preserve the identity event that made the original symbol successful.

Allowed:
- canonical vector preservation;
- technical cleanup;
- production preparation studies.

Forbidden:
- replacing the original symbol;
- changing identity-defining geometry without explicit decision.

### Lane B — C0 Refinement Studies

Purpose:
Explore controlled descendants of the original symbol.

Naming:
- C0-R1
- C0-R2
- C0-R3

Derived studies do not inherit C0 authority.

Allowed questions:
- optical balance;
- Bézier/vector precision;
- compact-size adaptation.

### Lane C — New Kymaean Symbol Concepts

Purpose:
Explore independent symbolic interpretations.

Possible themes:
- ensemble and convergence;
- resonance and cymatic structure;
- emergence of hidden order;
- human and AI collaboration;
- multiple perspectives becoming coherent.

New concepts are challengers, not replacements.

## Review requirement

Every symbol review must include:

1. Original C0 Threshold K.
2. C0-derived refinement candidates.
3. Independent concept candidates.

No candidate replaces C0 without an explicit Director decision.

## Design order

1. silhouette;
2. negative space;
3. geometry;
4. small-scale recognition;
5. context testing;
6. palette/material exploration.
