## Deterministic candidates

All candidates use the exact historical Threshold K paths, uniformly scaled/translated only, and the exact O3 `YMÆAN` path geometry.

- **A — O3 reset:** original O3 spacing and hierarchy: `v 5.9 / d 5.35 / h 4.55 / fine 2.35 @ .70`.
- **B — optical spacing:** A geometry/hierarchy, with intact glyph-group translations only: `Æ -3`, `A -3`, `N -4` SVG user units.
- **C — optical hierarchy:** B plus the smallest historical reduction-only hierarchy test: vertical strokes `5.9 -> 5.45`; all other O3 stroke classes unchanged.

## Required rendered shapes

Local Edge deterministic captures were inspected at:

- 2048 × 1199 wide;
- 1235 × 647 mini-wide;
- 1138 × 1354 tall computer browser.

Each shape used the same frozen Stage source and the existing V2.2 Stage crop mechanism. Full-page and lettering-crop inspection were both used because the B/C changes are intentionally small.

## Result

**A** confirms that O3 remains a sound structural base, but the `M–Æ` interval remains visibly looser than the surrounding cadence and the final `A–N` interval also carries slightly excess air.

**B** corrects those two interval pressures without changing any glyph path, baseline, scale, or stroke hierarchy. Across all three required shapes the wordmark reads more continuously while Threshold K remains the concentrated lead event. The correction is small enough that it does not become a new lettering style.

**C** is legible and controlled, but the vertical-stroke reduction does not solve an additional visible defect after B. At full composition scale it is nearly indistinguishable; at lettering-crop scale it slightly weakens the structural parity between `YMÆAN` and Threshold K. The extra hierarchy change is therefore not justified.
## Selection and boundary

Director and Design Sol converge on **B — optical spacing** as the successor lettering direction.

Preserve for the implementation candidate:

- exact historical Threshold K path geometry;
- exact O3 `YMÆAN` path geometry and original O3 stroke hierarchy;
- B's bounded group-only spacing translations;
- viewport center at 50%;
- the tighter status relationship and restrained lower vertical rhythm;
- the exact frozen Stage/crop architecture.

Reject C's hierarchy reduction and any further generated typography, per-letter vertical drift, added viewport frame, Stage repaint, or new copy.

This selects a non-production website identity successor direction only. It does not authorize deployment, final shared-brand geometry, app/UI changes, palette changes, product disclosure, or Stage revision.

**Next boundary:** materialize B as a production-shaped successor candidate while keeping live V2.2 unchanged, then run the complete responsive/accessibility/publication regression before any production promotion.
