# R0 Renderer Cartography — Persistent Affordance Carrier Synthesis 01

Status: **SYNTHESIS CHECKPOINT — NO NEW RENDER AUTHORIZED**

Updated: 2026-09-03

## Scope

This synthesis covers PAC-01A through PAC-01E.

The branch was created after the Semantic Observability / RST sequence showed that human-only still-image prompts could preserve identity, agency, relational history and asymmetric awareness, but repeatedly failed to make persistent enabled capability visibly recoverable.

The PAC branch deliberately introduced concrete ordinary carriers while attempting to keep people primary and suppress metaphor.

## Empirical progression

### PAC-01A — ordinary built carrier

Result:

> visible carrier -> plural supported use

Findings:

- a mundane persistent carrier restores visible plural affordance;
- human primacy and independent agency can survive the introduction of environment/object support;
- prior human shaping remains only partially recoverable;
- supported action is not necessarily carrier-dependent action.

### PAC-01B — repositionable ordinary elements

Result:

> movable objects -> plural object-level affordance

Finding:

> **Object affordance is not configuration affordance.**

The renderer used chairs, tables, crates and other mundane objects conventionally, but their relationships did not create new capability.

### PAC-01C — relational configuration

Result:

> multiple ordinary elements -> local emergent affordance

Findings:

> **Relational affordance can emerge locally without producing shared systemic affordance.**

> **Multiple local configurations are not the same as one shared capability-bearing configuration.**

### PAC-01D — shared overlap

Result:

> one shared arrangement -> overlapping use, but dominant-hub collapse

Finding:

> **Shared-element overlap is not distributed configuration dependence.**

A common table could serve many people without making the multi-element arrangement the causal capability-bearing unit.

### PAC-01E — no-single-element sufficiency

Result:

> distributed object cluster -> reduced hub dominance, but distributed necessity still not robustly observable

Finding:

> **Distributed carrier topology is not distributed configuration dependence.**

Removing one dominant hub caused the renderer to spread the carrier across many ordinary objects, but most actions remained explainable through familiar local affordances.

## What the branch validates

The following claims now have strong empirical support within the tested still-image regime:

1. people can remain structurally and semantically primary while concrete persistent carriers are present;
2. a concrete carrier can make present affordance more visible than human-only relational abstraction;
3. independent people can simultaneously use a persistent shared condition without helper/recipient hierarchy;
4. ordinary non-symbolic carriers can suppress the old bridge/threshold/monument/repair attractors;
5. relations among multiple objects can create locally emergent affordances;
6. common-use and common-cause are not the same;
7. visual distribution of objects is not evidence of distributed causal dependence.

## What the branch does not validate

The following remain unproven in a single static artwork under the current controls:

1. that a present persistent condition was definitely created by prior human choices rather than merely existing;
2. that several independent capabilities are visibly caused by one shared multi-element configuration;
3. that no single object or familiar local affordance adequately explains the relevant actions;
4. that human-created enabled possibility can be made fully legible without either:
   - literalizing the mechanism;
   - turning the carrier into the protagonist;
   - creating a contraption/product/installation;
   - or adding narrative explanation.

## Major methodological conclusion

The PAC branch has reached a still-image observability boundary.

The evidence now suggests that asking one static artwork to simultaneously prove:

- prior human authorship;
- persistent consequence;
- distributed enabled capability;
- independent agency;
- and non-symbolic human primacy

may exceed what can be robustly recovered from posture, arrangement and ordinary objects alone without literalization.

This is not a failure of the project thesis.

It is a measurement result:

> **Not every system law must be directly observable in one static visual surface.**

## Strategic implication for Kymaean visual language research

Do not force the entire internal thesis into a single hero image.

A stronger cross-surface model may allocate semantic burden across media:

- static artwork can carry human specificity, relational field, independent agency, persistent consequence and asymmetric position;
- sequence, motion or interaction may carry before/after, authorship, propagation and enabled possibility;
- interface/website composition can reveal persistence and changed capability through state transitions rather than symbolic objects.

This is a research direction, not an R1 or production authorization.

## Candidate next checkpoint

Before any new image, audit whether R0 should move from **single-static semantic compression** to **cross-medium semantic allocation**.

Possible research questions:

1. Which Kymaean laws are directly observable in a still image?
2. Which require temporal sequence or interaction?
3. Which should remain internal generative constraints rather than user-visible claims?
4. Can a two-state or motion experiment recover human authorship and enabled possibility without returning to literal crossing/repair metaphors?
5. What is the minimum additional temporal information needed beyond a still image?

Do not render another PAC image until this allocation question is resolved.
