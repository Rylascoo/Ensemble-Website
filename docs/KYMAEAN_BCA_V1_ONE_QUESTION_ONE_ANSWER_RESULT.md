## 0. Purpose

Record the controlled BCA-V1 result without promoting its mocked answer content, cast, scene, or interface surface into project authority.

BCA-V1 tested whether one current anchor plus one explicit creator question could produce one compact contextual answer without reverting to a Character dossier, evidence taxonomy, transcript wall, history panel, or generic AI-chat loop.

The experiment used the established SIPD/CDT semantic baseline:

- Production `P0`;
- Scene `S0`;
- Characters A / B / C;

- creator posture = Watch;

- context anchored on C / Current Opportunity C;

The rendered surface is research evidence only.

## 1. Overall judgment

> **BCA-V1 — ANSWER-COMPOSITION PASS / AUTHORITY-SOURCING FAIL.**

The experiment successfully demonstrates the BCA information shape:

```text
anchor + exact question
    -> one direct answer
        -> minimum supporting basis
            -> one next path / return
```

The renderer filled the answer from visible/narrative meeting cues rather than from a supplied authoritative Production source set.

Therefore:

> **The answer format works; renderer-authored factual completion does not.**

## 6. Bounded insufficiency discovery

BCA-V1 exposes a deeper trust requirement.

For some questions, current authoritative state may not contain enough permitted information to answer the requested explanation.

That is not a UI failure.

Correct behavior is:

```text
question
    -> permitted authoritative source search
        -> sufficient support exists?
            yes -> compose minimum supported answer
            no  -> state bounded insufficiency truthfully
```

The system must not fill the epistemic gap with:

- scene interpretation;
- probable narrative completion;
- Character psychology;
- generic model reasoning presented as fact;
- inaccessible information;
- stale or foreign context.

A truthful bounded answer may therefore say that the current state establishes a fact but does not currently establish the requested reason.

Patch 0013's effective opportunity event canonically records:

- selected Character ID.

The Production transition changes only `CurrentOpportunityCharacterId` and does not write fictional Character/World/Relationship/Pressure state.

The opportunity event does not embed full Director trace, Context prose, Candidate prose/control, or diagnostic explanation.

Therefore the current Production fact `C has Current Opportunity` is not, by itself, an authoritative natural-language reason such as `C is leading the discussion`.

A deeper causal answer requires separately available causal/Director authority and an explicitly historical/trace route; if that source authority is unavailable, bounded insufficiency is the correct result.
