## Purpose

Define one deterministic website-integration test surface before Qualifying Round 01 so Brand Integration, Mobile Survival and S6 cannot be rescued by candidate-specific layout changes after a renderer output exists.

This harness is evidence infrastructure, not production website implementation.

## Global-sequence law

If the Director approves this pre-render package, Harness 01 becomes the global integration harness for every qualifying hero candidate in the current sequence.

It may not be moved, resized, recolored, masked, re-cropped or otherwise adapted to favor a returned candidate. Changing it after Round 01 begins requires halting the experiment and explicitly reopening the method rather than silently rescuing an image.

## Candidate-artwork handling

The untouched renderer output remains the raw authority for E2-E4 evaluation.

Harness evidence may perform only deterministic:

- scale;
- crop;
- placement;
- compositing with the fixed website identity/copy scaffold.

No inpainting, outpainting, object removal, repainting, recoloring, relighting, candidate-specific masks, candidate-specific gradients or local retouching are permitted.

The executable harness contains exactly one candidate substitution token: `__CANDIDATE_ARTWORK__`.

## Desktop evidence frame

Fixed hero evidence frame:

- viewport / frame: **1280 × 720 CSS px**;
- candidate artwork: full-frame `object-fit: cover`;
- candidate artwork position: **50% 50%**;
- no candidate-specific scrim or backdrop between artwork and identity;
- calm identity/copy target region: left **40%** of the hero frame;
- denser consequential region is expected primarily center/right.

Fixed identity/copy scaffold:

- horizontal inset: **6%** of frame width;
- top inset: **12%** of frame height;
- copy block maximum width: **38%** of frame width;
- Threshold K source: `assets/brand/kymaean-threshold-k-working-candidate.svg`, unchanged;
- Threshold K displayed height: **52 CSS px**;
- O3 source: `assets/brand/kymaean-o3-wordmark-temporary-incumbent.svg`, unchanged;
- O3 displayed width: **360 CSS px**, constrained to the copy block;
- fixed scaffold eyebrow: `Local-first generative theater`;
- fixed scaffold heading: `A world with continuity, not a stream of replies.`;
- fixed scaffold supporting line: `One persistent Production carries Characters, world conditions, bounded knowledge and committed consequence forward.`

The scaffold copy is measurement text taken directly from current Site Spine language. It is not final website copy and gains no production authority through this harness.

No outline is drawn around the left 40% in scored evidence. The percentage exists as a pre-registered geometry constraint, not visible UI.

## Mobile evidence frame

Fixed mobile evidence viewport:

- viewport width: **390 CSS px**;
- identity band: **390 × 150 CSS px** on Mineral Theater Void;
- candidate-artwork crop frame: **390 × 488 CSS px** — exact **4:5**;
- candidate artwork: same untouched raw output as desktop;
- crop method: `object-fit: cover`;
- crop position: **72% 50%**;
- no manual focal-point adjustment after generation.

The mobile identity band contains unchanged Threshold K + O3 and the same fixed eyebrow only. The artwork crop remains visually separate enough that the test measures semantic survival rather than text legibility over every possible image region.

The mobile crop must preserve at least:

1. two people that were necessary in the raw candidate; and
2. visible evidence of the changed shared condition.

If the fixed crop loses that semantic minimum, Mobile Survival fails. Do not search for a better crop.
