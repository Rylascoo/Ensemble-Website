## Primary synthesis

O0-B is not missing the product's core idea. It is missing **state completeness and authority completeness** around a compelling in-Production experience.

The strongest refinements therefore come from extending the family outward and downward:

```text
APPLICATION SCOPE
Production entry / create / open / switch
        ↓
O0-B1 REFINED
shape possibility
        ↓
O0-B2/B3 REFINED
live performance + bounded perspective
        ↓
ACCEPT / REJECT / ANOTHER TAKE
make authority transition explicit
        ↓
O0-B4 REFINED
causal history + unresolved continuity
        ↓
changed present
```

## First rendered gap

The first rendered refinement should target **application scope before O0-B1**:

> Production entry / empty Production / open existing Production.

This is the highest-leverage missing surface that does not depend on unresolved Stage performance rhythm or final Character medium.

## Audit result

- No later architecture requires O0-B to be discarded.
- No O0-B surface by itself solves Production lifecycle.
- The front-door surface can be designed without selecting cone/cylinder Stage geometry, final wordmark or final motion timing.
- The front door must not imply that provider configuration is required to own/open/edit local Production state.
