# KYMAEAN LANE B — WEBSITE VISUAL-WORLD COMPOSITION 01

Date: 2026-09-05  
Workstream: LANE B / V0 WEBSITE VISUAL WORLD

## Authority entering

This round uses:
- historical Threshold K through the deterministic testing adapter; Threshold K remains a non-final working symbol candidate/control;
- Director-approved temporary O3 Balanced Hierarchy wordmark incumbent;
- Director-approved temporary deployment laws;

The website remains an expressive explanatory/acquisition environment. It is not a browser implementation of the native app.

## Frozen question

How should Kymaean's website become visually expressive without:
- imitating app UI;
- collapsing into generic dark atmosphere;
- turning Threshold K into a literal portal/threshold illustration;
- asking O3 to carry the entire visual identity;
- losing the project's otherworldly, symbolic, organic, architectural, historical, typographic, relational and theatrical range?

Three genuinely different hypotheses were frozen before evaluation.

## A — Inhabited Interval

Primary device: **architecture / spatial interval / changed adjacency**.

Strengths:
- clearly distinct from native app UI;
- spatial composition can express consequence and changed possibility;
- adapts to mobile without preserving a desktop diagram;
- supports a light-field Kymaean world rather than assuming permanent black.

Failure pressure:
- least specifically Kymaean of the three;
- can drift toward cultivated architecture/cultural-institution branding;
- the spatial-gap device risks re-entering literal threshold/portal shorthand;
- human presences become abstract notation more quickly than the project prefers.

Result: **RANK 3 / DO NOT ADVANCE AS PRIMARY WEB WORLD.**

Preserve only as spatial-composition research.

## B — Living Marginalia

Primary device: **typography / historical residue / annotation / interrupted trace**.

The page behaves like an active authored field rather than a manuscript replica. History appears as residue and present-tense interruption instead of a permanent timeline.

Strengths:
- strongest direct continuation of the project's “The Word” opportunity;
- historical texture can exist without faux-antique ornament;
- naturally supports Archive/history/consequence material;
- mobile becomes editorial and sequential rather than a mini desktop;
- clearly avoids app UI imitation.

Failure pressure:
- can become literary-brand collage rather than generative theater;
- depends heavily on copy quality;
- annotation can become explanation instead of world;
- insufficient restraint could produce museum/editorial rather than Kymaean.

Audit correction: the first render used a large generic serif `KYMÆAN` as background typography, silently introducing an unauthorized alternate rendering of the brand name beside approved O3. The background word was changed to `HISTORY`; only approved O3 now renders `KYMÆAN` as identity.

Result: **RANK 2 / RETAIN AS SECONDARY EDITORIAL-HISTORY RESEARCH, NOT PRIMARY WORLD.**

This is not permission to merge its devices into another direction during the current round.

## C — Quiet Stage

Primary device: **theatrical absence / volumes of presence / restrained product truth**.

The current cone Stage study appears as atmospheric evidence rather than interface. No app controls, panels, focus indicators, speaking state or Stage affordance enters the website hero.

Strengths:
- strongest immediate sense of product belonging;
- strongest Threshold K + O3 hierarchy;
- most successful mobile composition;
- website remains expressive while the app remains operational;
- carries human/presence/theatrical meaning without depicting AI, chat or generic software;
- brand can lead on acquisition surfaces without displacing product truth.

Failure pressure:
- can overfit the current Stage carrier;
- can become a screenshot/gallery site;
- black theatrical atmosphere alone would narrow the project's broader artistic range;
- must prove it can extend into history, relationship and consequence without relying on cones.

Result: **RANK 1 / RECOMMENDED SURVIVOR FOR PRIMARY WEB-WORLD REFINEMENT.**

## Recommendation

Advance **C — Quiet Stage** as the primary V0 visual-world refinement incumbent, subject to Director approval.

This recommendation is intentionally narrower than “make the website look like the Stage.”

The next proof must preserve:
- theatrical absence;
- human/presence priority;
- Threshold K as concentrated prelude;
- O3 as owned name;
- product truth without app-interface imitation;
- responsive asymmetry;

while demonstrating at least three non-hero extensions where cone imagery is not the organizing device:
1. relationship / bounded perspective;
2. history / Archive / consequence;
3. creator posture / Production invitation.

If Quiet Stage cannot expand beyond cone imagery without becoming generic darkness, it should fail the next gate.
