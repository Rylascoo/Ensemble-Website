# Kymaean — Hero Surface Escape Gate 01

Status: FROZEN BEFORE SURFACE PROMPT
Date frozen: 2026-09-05

## Purpose

Prevent another sequence of renders being described as “closer” without a falsifiable definition of escaping historical-domestic realism.

## Hard gate — ORDINARY TASK TABLEAU MUST BE ABSENT

A surface-divergence render fails if its primary literal reading can be summarized as:

**“a person doing a recognizable ordinary task or responding to an ordinary accident in a conventional historical/domestic/occupational setting.”**

Automatic-failure examples include a central read equivalent to cleaning a spill, repairing/maintaining, farming/gardening, carrying/arranging household goods, cooking/serving, excavation/construction, routine workshop labor, housekeeping, or ordinary accident cleanup.

The gate concerns the image's primary visual identity, not whether such an object happens to appear somewhere in frame.

## Operational falsification test

Ask before any aesthetic preference:

> If the impossible/material physics were removed, would the image still read coherently as a conventional period/domestic/work genre tableau?

- YES -> FAIL surface escape.
- NO -> PASS the hard surface gate.

A pass does not mean the image is good or final. It only means it escaped this specific attractor.

## Secondary observations — not hard gates yet

Record without retroactive promotion to mandatory criteria:
- fantasy / videogame-key-art drift;
- luxury/editorial drift;
- AI-tech/sci-fi drift;
- portal/threshold shorthand;
- generic cinematic-surrealism drift;
- overdependence on one spectacular effect.

## Rule

This gate is frozen before any surface-divergence prompt is authored.
