## 1. Purpose

V0R6 resolves the V0R5 single-carrier failure but exposes a narrower distinction:

> **A composition can depend on several people being present without depending on the particular actions those people perform.**

AFI-01 asks:

> **How can the depicted field become materially dependent on several specific human actions, so changing those actions changes the field even if the people remain in approximately the same places?**

This remains H5 `Expressive Performance Field` research. It does not select a visual family.

## 2. Governing distinction

### Presence-field dependency

The image changes because bodies occupy different regions, colors and masses.

This can satisfy a person-removal test while remaining largely insensitive to what each person is doing.

### Action-field dependency

The image changes because the actions themselves alter:

- contour direction;
- opening/compression of negative space;
- overlap sequence;
- directional flow;
- local plane shape;
- density;
- interruption/resumption;
- the active region another person occupies.

The same person in roughly the same region performing a materially different action should create a meaningfully different field.

Promoted distinction:

```text
presence-field dependency
!=
action-field dependency
```

## 3. Action-substitution test

A future H5 image should be tested with this counterfactual:

> **Keep a relevant person in approximately the same location and scale, but replace their action with a materially different one. Would the field still organize itself almost the same way?**

If yes, that part of the field is probably presence-driven rather than action-driven.

A successful performance-field probe should make at least several actions structurally consequential.

## 4. Distributed interaction requirement

The field should not require harmony or common intent.

Useful interaction classes include:

- one action redirects another person's path;
- one action opens a region another person can occupy;
- one action compresses another person's available space;
- one action interrupts a visual continuation another action resumes elsewhere;
- one action causes a local figure-ground reversal that changes another person's field;
- one person's withdrawal, refusal or continuation forces another action into a different visual route.

These are compositional possibilities, not fictional-story requirements or UI states.

## 5. Epistemic restraint

Do not infer or require:

- shared intention;
- cooperation;
- hierarchy;
- motive;
- knowledge;
- emotion;
- agreement;
- private response.

Visible action-response must be enough.

Therefore a small renderer micro-batch may be used when all images answer one bounded comparative question and each image still uses its own clean disposable Renderer Context.

For AFI-01 the justified comparative question is:

> **Can action-field dependency survive two deliberately orthogonal depiction grammars without one grammar becoming an incumbent merely because it renders first?**

Authorized batch size:

> **Two isolated images, each generated in a different fresh regular non-project chat, using one packet each.**

One-image-per-renderer-chat remains mandatory. The two images may be returned together to the Director for comparative analysis.

This is not convergence and does not authorize refinement of either result.

## 7. Formal probes

### Probe A — distributed flat-plane field

Controls the image toward:

- shallow depth;
- discrete interlocking planes;
- strong negative space;
- limited continuous modeling;
- action-driven plane interruption and compression;
- selective environment.

### Probe B — contour / void field

Controls the image toward:

- sparse contour and local detail;
- large open voids;
- contour breaking/resuming around different actions;
- line density changing according to action;
- very selective spatial cues;
- human specificity without a fully modeled scene.

Neither grammar is a proposed Kymaean identity. They are orthogonal test surfaces.

## 8. Falsification conditions

A probe fails action-field dependency if:

1. replacing a person's action while preserving approximate body placement leaves the field essentially unchanged;
2. one large object carries most of the field;
3. figures are simply arranged as balanced color masses;
4. all action remains local and mutually irrelevant;
5. graphic structure is decorative rather than action-dependent;
6. people synchronize into one collective gesture;
7. human identity collapses into anonymous icons;
8. the result becomes a diagram, poster, interface or explanatory board;
9. a formal probe merely returns another densely modeled painterly interior;
10. one successful image is treated as a selected family.
