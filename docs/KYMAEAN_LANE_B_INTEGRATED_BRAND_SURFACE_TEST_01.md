Status: STATIC INTEGRATION STUDY COMPLETE / DIRECTOR DEPLOYMENT GATE  
Date: 2026-09-05  
Workstream: SHARED BRAND / X0 INTEGRATION

## Inputs

This round uses two distinct current authorities without upgrading either one:

- **Threshold K** — unchanged historical working symbol candidate/control; not final logo.
- **O3 Balanced Hierarchy** — Director-approved temporary W0 wordmark incumbent for integrated app + website testing; not final wordmark.

The mark geometry is not reopened. O3 geometry is not redesigned.

## Question

Can Threshold K + O3 inhabit Kymaean's real product and website roles without making the application feel like a marketing surface, turning the symbol into an interface affordance, making O3 imitate Threshold K, or requiring one fixed mark/name hierarchy everywhere?

## Integration law

**Inside the app, brand recedes behind Production. On the website, brand may lead.**

Identity invariance does not require a fixed lockup ratio.

## Static results

### Dense native app

O0 Studio and Character View were used only as dense-shell contextual evidence. Their historical top-left `Ensemble` brand slot was replaced; no other O0 surface decision is promoted by this overlay.

Result: compact Threshold K + O3 remains recoverable while Production and character-bounded content remain primary.

**PASS — product-first hierarchy.**

### Current Stage carrier

The selected cone/volume-of-light Stage direction was placed inside a restrained Kymaean shell.

Result: Threshold K + O3 remain shell identity only; neither enters floor pools, cone bodies, name labels, selection/focus grammar, speaking state or Take-a-Seat semantics.

**PASS — semantic separation.**

### Website navigation

The website permits more scale and mark/name separation than app chrome.

Result: Threshold K works as an independent lead element; O3 gets enough room for its custom `Æ`; navigation still reads as navigation rather than a logo banner.

**PASS — restrained identity establishment.**

### Website hero

Brand is permitted to become the first visual event.

Result: Threshold K can lead as the concentrated visual event and O3 follows as the human-readable name; a forced large horizontal parity lockup is unnecessary. Visible descriptive copy is product-truth scaffolding only, not selected website copy.

**PASS — asymmetric expressive hierarchy.**

### O3 standalone

O3 was shown without Threshold K on dark and light fields.

Result: the word remains identifiable as its own designed asset; no extra Threshold K echo is justified.

**PASS — standalone wordmark identity.**

## Current recommendation

Accept these as **temporary shared-brand deployment laws for continued design testing**:

1. app chrome uses a quiet compact mark + O3 lockup;
2. Stage keeps all brand geometry outside Stage presence/focus/speaking semantics;
3. website header uses more breathing room than app chrome;
4. website hero may use Threshold K as prelude and O3 as the owned name;
5. O3 may appear without Threshold K;
6. there is no universal fixed mark/name ratio.

This is a Director gate. The study does **not** select final Threshold K, final O3 production master, app icon, palette, website visual world/copy, trademark clearance, or runtime raster/accessibility behavior.
