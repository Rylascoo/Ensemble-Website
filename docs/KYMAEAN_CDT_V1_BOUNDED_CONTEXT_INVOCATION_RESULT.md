## 3. Structural passes

### 3.1 Stage continuity — PASS

The Production remains perceptually retained while context is open. A/B/C, the current Scene, Watch posture and Current Opportunity remain visible.

The interaction reads as inspection of the same Production rather than a switch into a separate product or dossier workspace.

### 3.2 Anchor relationship — STRONG PASS

The context surface is explicitly anchored to:

`C — Vale`

and states that it contains information available to B in the current Scene.

This preserves the critical distinction:

```text
anchor = C
perspective = B
locus = current
```

Selecting C does not imply becoming C.

### 3.3 Watch continuity — STRONG PASS

Opening context does not expose Character portrayal controls, a Perform composer, `Speak as`, `Act as`, or equivalent agency leakage.

> **Inspecting context while Watch is active remains Watch.**

### 3.4 Opportunity continuity — STRONG PASS

Current Opportunity remains C and remains explicitly non-obligatory.

The render supports:

```text
inspect C
!= assign opportunity to C

open context
!= consume opportunity
```

### 3.5 Return affordance — PASS

`Back to Scene` and close affordances make the disclosure state clearly reversible.

The baseline Stage remains visually intact enough that exact semantic restoration is credible without requiring a third render.

### 3.6 Static/reduced-motion viability — PASS

The transition meaning is legible in a still state. No animation is required for semantic correctness.

## 4. Disclosure-content failures

### 4.1 Context becomes too schema-complete — PARTIAL FAIL

The panel exposes several adjacent information destinations and evidence classes simultaneously:

- Current Context;
- Related Details;
- Causal Trace;
- What I Can Observe;
- What I Heard;
- What Is Established.

This drifts toward:

```text
select Character
-> open compact Character information portal
```

rather than the CDT target:

```text
follow one current question
-> receive one bounded answer
```

The successful transition must therefore not be mistaken for approval of this information density or taxonomy.

Required correction:

> **Contextual disclosure should be question-bounded, not schema-complete.**

### 4.2 Observation authority overclaim — FAIL

The `What I Can Observe` section promotes rendered Scene cues into authoritative B-observation claims, including statements equivalent to:

- C is using notes on the table;
- C is looking at B.

Current Patch 0014 authority does not establish Character observation merely from visible Scene content, co-presence, dialogue visibility, relationship, SceneState or causal adjacency.

Therefore:

```text
visible in Stage representation
!=
observed by B
```

This is a material trust-model failure and must not survive into the next contract.

### 4.3 Performance/transcript evidence remains future hypothesis — PARTIAL

The `What I Heard` section contains quoted recent dialogue.

Current Patch 0014 canonical Context v2 still has:

```text
recentPerformances = []
RecentPerformanceText = empty
```

Therefore the render is useful future UX research but does not establish that current application architecture can populate this content.

### 4.4 `What Is Established` is directionally strongest — PARTIAL PASS

Current authoritative facts are the strongest content class in the panel because they can answer what is true now without inventing psychology.

However every statement still requires actual underlying authority. Language such as `next steps are being defined` cannot be inferred merely from conversational appearance.

### 4.5 Causal Trace is too prominent as a sibling route — PARTIAL FAIL

`Causal Trace` appears as a standing peer of Current Context.

CDT requires current-context expansion and historical/causal-trace expansion to remain distinct semantic routes.

Preferred direction:

```text
current authoritative fact
-> user asks Why?
-> enter causal trace
```

rather than treating history as a universal Character-context tab.
