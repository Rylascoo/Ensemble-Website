# Ensemble Website

Website and public-brand development for **Kymaean**, the future public identity of the product currently developed in `Rylascoo/Ensemble-Project`.

## Fresh-chat bootstrap

Before making brand, visual, motion, asset, or website changes:

1. Read [`CURRENT_STATE.md`](CURRENT_STATE.md) first.
2. Read [`docs/DESIGN_CONTINUITY.md`](docs/DESIGN_CONTINUITY.md).
3. Read the current `Rylascoo/Ensemble-Project/CURRENT_STATE.md` and only the product sources relevant to the task.
4. Treat Google Drive **Ensemble Project** as the visual-master/design authority.

Do not infer that praise, recency, or an attractive exploration means a direction has been selected. Exploration remains broad until explicit mutual convergence.

## Repository boundary

- **This repository:** website implementation specifications, source, tests, deployment configuration, and approved optimized web derivatives.
- **Google Drive — Ensemble Project:** visual masters, identity explorations, mockups, artwork, motion studies, and design references.
- **Rylascoo/Ensemble-Project:** authoritative product engineering source; read-only for website work unless explicitly instructed otherwise.
